# Third-party asset record

The production map uses a small set of CC0 GLB decorations. They are committed
with the project because the selected license permits use, modification, and
redistribution, including in open-source and commercial work.

The authoritative per-file provenance and hashes are stored beside the assets
in `public/models/landmarks/cc0/README.md`.

The assets remain optional. If a GLB fails to load, the procedural sect model
continues to render and the map remains usable.
